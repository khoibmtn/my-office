# Save Project Context

Update or create project-owned context files such as `CODEBASE.md` and `docs/SESSION_NOTES.md` with the current architecture, decisions, changes, known issues, and pending work. Read existing files first and keep the result concise and factual.

This skill does not stage, commit, merge, push, pull, switch branches, deploy, or run destructive cleanup. Those actions require a separate explicit user request.
